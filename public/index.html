StaticPHP prebuilt PHP

One endpoint that redirects to the newest published static PHP binary on dl.static-php.dev.

GET /fetch.php?combination=common&version=8.4&os=linux&arch=x86_64&sapi=cli
GET /fetch.php?combination=common&version=8.4&os=linux&arch=x86_64&sapi=cli&format=json

Parameters

namevaluesdefault
combinationminimal, common, bulk, gnu-bulk, spc-min, spc-maxcommon
version8.2, 8.3, 8.4, 8.5, an exact patch (8.3.36) or latestlatest
oslinux, macos, windowslinux
archx86_64, aarch64 (amd64/arm64/x64 accepted)x86_64
sapicli, micro, fpm (fpm is unix only)cli
formatjson returns the resolution instead of redirecting

Client scripts

# Linux / macOS: the shell client defaults to the unix combinations
curl -fsSLO https://staticphp.sh/fetch.sh && chmod +x fetch.sh && ./fetch.sh -v 8.4 -c bulk

# Windows: the PowerShell client defaults to spc-max, the Windows combination
iwr -useb https://staticphp.sh/fetch.ps1 -OutFile fetch.ps1; .\fetch.ps1 -Version 8.4

Examples

curl -fL -o php "https://staticphp.sh/fetch.php?combination=bulk&version=8.3&os=linux&arch=aarch64&sapi=cli"
curl -fsSL "https://staticphp.sh/fetch.php?combination=bulk&version=8.3&sapi=micro&format=json"
